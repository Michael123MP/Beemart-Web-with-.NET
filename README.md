# 🛒 BeeMart - Point of Sale (POS) Web Application
BeeMart is a modern web-based POS for managing product inventory, cashier transactions, and sales history in real-time. This was build with a full-stack development approach, using ASP.NET Core & Web API as the backend, CSHTML + CSS + Javascrpt for the frontend, and SQL Server as the main database server

## 🚀 Tech Stack

**Backend**: ASP.NET Core MVC / Web API, C#,
**Frontend**: HTML5, CSS3, JavaScript, CSHTML (Razor Pages)
**Database**: Microsoft SQL Server 
**Keamanan**: ASP.NET Core Identity / Password Hashing

## ✨ Key Features
1. **Authentication & Otorization**: Secure login system with password hashing encryption
2. **Interactive Product Catalogue**: Managing product stock, price, transaction in real-time 
3. **Transaction Cart**: Automatic calculation of subtotal, discounts, and total purchase price
4. **Transaction History**: Recording of unique invoice numbers and recapitulation of transaction data by cashier and date.
